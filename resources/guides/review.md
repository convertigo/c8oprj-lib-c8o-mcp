# Convertigo Project Review Guide

Frame the requested scope and review mode before inspecting. Use MCP read-only inspection and project-security-audit; distinguish observed defects, risks and untested behavior. Compare V1/V2 on the same criteria. Prioritize user impact, security, correctness and maintainability with concrete object QNames and evidence. Never claim static review proves runtime behavior. Produce the requested report and explicit validation limits; do not mutate the reviewed project without authorization.
