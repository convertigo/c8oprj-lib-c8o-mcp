# Convertigo CRUD Fast Path

For a new standard SQL CRUD + NGX app: marketplace-import template_ngxBuilderIonic with the exact requested name -> mobile-builder-open(wait=false) -> upsert-crud -> backend crud-proof -> optional ngx-theme-apply for a requested brand -> one ngx-page-create per page -> viewer readiness -> project-lint -> browser-verify -> project-save. Create Login first with root:true, locale and currency; use home/authRedirect on feature pages and a logout page. Use generated business sequences and explicit relations/seed data. Generated auth_login is a demo skeleton; replace it before delivery. Stop at the first green requested scaffold; never repair generated artifacts. Before deployment/export run mobile-builder-build.
