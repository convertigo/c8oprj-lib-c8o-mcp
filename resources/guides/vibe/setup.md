# Convertigo Vibe Start

## When to read this
Read this after `convertigo://guides/start` when the caller is Mistral Vibe or a Vibe-based headless benchmark.

## Adapter scope
This guide is only the Vibe adapter layer. It does not replace the shared Convertigo guides. Use it to make Vibe load the MCP catalog, keep benchmark runs isolated, and then fall back to the same recipes used by Codex and other MCP clients.

All constraints in this adapter are technical invariants: MCP call ordering, object creation, readback, proof, binding modes, error handling, and generated-artifact boundaries. Do not treat benchmark scenarios as reusable product guidance, and do not add provider-, dataset-, country-, language-, or feature-specific requirements to the skill unless the current user task explicitly asks for them.

## Setup sequence
Run `lib_ConvertigoMCP._setupVibe` once for the target Vibe home.

Recommended variables for benchmark and skill-adjustment loops:

```json
{
  "vibeHome": "/path/to/isolated/vibe-home",
  "mcpUrl": "http://localhost:18080/convertigo/api/mcp",
  "replaceConfig": true
}
```

`replaceConfig=true` is intended for isolated homes. It writes a deterministic `config.toml`, an `AGENTS.md`, and the `convertigo-vibe-generalist` skill. Do not use it on a personal Vibe home unless replacing that configuration is intentional.

For a personal Vibe home, omit `replaceConfig` so the setup patches missing Convertigo entries and leaves existing skill filters intact.

## Mandatory Vibe bootstrap
1. Use the `convertigo-vibe-generalist` skill.
2. Use the MCP server named `Convertigo`.
3. Read `convertigo://capabilities` once and compare the installed skill guidance version.
4. Read a known URI directly with `Convertigo_requestable-execute`, `requestable:"lib_ConvertigoMCP.mcp_resources_read"`, `variables:{uri:"<exact-uri>"}`, `includeLogs:false`. Read one guide per call; never batch guide reads.
5. Use catalog discovery only if routing is ambiguous, a named resource is missing, or guidance versions disagree. The short start and adapter summaries are `convertigo://guides/start` and `convertigo://guides/vibe`.
6. Pick the smallest matching shared recipe before mutation (routes in `convertigo://resources/convertigo-task-routes`). A new application built from a specification with several pages, roles or a session and SQL persistence is the `new-multipage-app` route: read `convertigo://guides/multipage`.

## Fewer calls, same method
The Convertigo method is the shared one: the common skill (Tool economy in `convertigo://guides/common/batching`, NGX and backend invariants) and the shared recipes apply to Vibe as they are. Only the harness mechanics differ: `Convertigo_*` tool names and guide reads through `mcp_resources_read`. Apply the common skill's rules that cut calls: tree shortcuts and steps sourced by name, and independent lots in one `batch-call` with `callsFile`. Large trees are generated by a script into the `callsFile` JSON rather than written by hand in an argument, where nested JSON is where Vibe runs fail.
