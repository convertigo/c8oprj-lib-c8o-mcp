# Convertigo Backend Sequences

A sequence is a step tree, not a JavaScript replacement for connectors. Discover classes/properties in the live palette. Keep transport in typed transactions and call them with TransactionStep using Project.Connector.Transaction. Sources need the real producer step priority plus XPath; output=true exposes data, not execution order. Prove a stable public application contract and variable forwarding with requestable-execute before UI work. Never treat metadata/status alone as proof. Inspect, mutate through MCP, test, then project-save; no descriptor or generated-file edits.
