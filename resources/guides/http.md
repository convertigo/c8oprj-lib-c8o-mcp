# Convertigo HTTP Integration

Use HttpConnector and a typed HTTP transaction, not HTTP calls in JavaScript. Read back server/baseDir/subDir, headers and RequestableHttpVariable contracts. Prove the transaction first, then the business sequence with public variables and application data. JSON/XML body shape and content type matter as much as status. Source picker tuples require producer priority plus XPath. Do not replace a failed service with sample data. Save with project-save after proof.
