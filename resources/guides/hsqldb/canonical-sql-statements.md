## Canonical SQL statements
Stay literal and boring on the first pass. Copy these statements first, then edit only if the current project proves a different variant is required.

### `init_schema`
- create tables with `CREATE TABLE IF NOT EXISTS`
- seed deterministically with `DELETE` then `INSERT`
- do not start with `MERGE INTO`
- HSQLDB numbers an identity column from 0 unless it says `(START WITH 1)`: a demo row that references its parent as id 1 then gets the second row, without error. Write `GENERATED BY DEFAULT AS IDENTITY (START WITH 1)`.
- a reseed that deletes the rows does not reset the identity counters: after `DELETE FROM t` the next ids go on from the last one, so a demo row that references another by a fixed id (`rpca_id = 2`) fails on the second seed with "foreign key no parent". Restart the counter in the reset (`ALTER TABLE t ALTER COLUMN id RESTART WITH 1` after its `DELETE`), or look the parent up by a natural key (`INSERT INTO child (parent_id, ...) SELECT id, ... FROM parent WHERE email = 'a@example.test'`). Remember that a failing write in a sequence does not stop it: check each `TransactionStep` result.

Example shape:

```sql
CREATE TABLE IF NOT EXISTS contacts (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY (START WITH 1) PRIMARY KEY,
  full_name VARCHAR(128) NOT NULL,
  company_name VARCHAR(128),
  email VARCHAR(160),
  status VARCHAR(32)
);

CREATE TABLE IF NOT EXISTS companies (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY (START WITH 1) PRIMARY KEY,
  company_name VARCHAR(128) NOT NULL,
  industry VARCHAR(64),
  city VARCHAR(96),
  status VARCHAR(32)
);

DELETE FROM contacts;
DELETE FROM companies;

INSERT INTO contacts (full_name, company_name, email, status) VALUES
  ('Ada Lovelace', 'Analytical Engines', 'ada@example.test', 'lead'),
  ('Grace Hopper', 'Compilers Inc', 'grace@example.test', 'customer');

INSERT INTO companies (company_name, industry, city, status) VALUES
  ('Analytical Engines', 'R&D', 'London', 'active'),
  ('Compilers Inc', 'Software', 'New York', 'active');
```

### `list_contacts`
```sql
SELECT id, full_name, company_name, email, status
FROM contacts
ORDER BY id ASC
```

### `count_contacts`
```sql
SELECT COUNT(*) AS total
FROM contacts
```

### `list_companies`
```sql
SELECT id, company_name, industry, city, status
FROM companies
ORDER BY id ASC
```

### `count_companies`
```sql
SELECT COUNT(*) AS total
FROM companies
```
