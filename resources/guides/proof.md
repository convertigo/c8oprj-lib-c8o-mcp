# Convertigo Validation and Evidence

A successful mutation or green build is not runtime proof. Execute the requested backend contract and test visible acceptance criteria, normal/empty/error states and persistence. Use the managed viewer, fix source objects, then project-save; reload only after saving. Report unavailable or failed checks explicitly.
