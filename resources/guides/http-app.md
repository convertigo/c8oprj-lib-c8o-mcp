# Convertigo Vibe HTTP NGX Fast Path

This fast path keeps one HTTP provider/connector rail. Choose a direct record endpoint satisfying the requested domain; no generic lookup/catalog or static-file substitute. Use HttpConnector + JsonHttpTransaction + RequestableHttpVariable; prove records with only the public filter first. On transport/shape failure allow one evidence-based same-rail repair, then report incomplete; never silently switch host/provider or replace HTTP with stubs. Keep public variable names identical through transaction, sequence, StepVariable and UI. TransactionStep.sourceTransaction uses Project.Connector.Transaction. Shape application data before UI. Build palette NGX events/actions and SC locals, prove visible behavior, then project-save. Never patch generated artifacts.
