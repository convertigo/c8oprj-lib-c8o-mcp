# Convertigo common guidance

Convertigo MCP is the authoring surface: inspect, mutate, prove, then project-save. Never edit project YAML/XML or generated artifacts. Compare guidance versions once; choose one route and read only its recipe. Keep exact project names. Use standard marketplace libraries, including _ui_ngx for NGX. Order dependent writes in batch-call. Backend transport stays in typed transactions; prove application data. NGX calls use events/actions, SC locals and valid SmartSources; siblings run in parallel, children await. Preserve scriptContent markers. Prove visible behavior, report gaps, and keep secrets in symbols with harmless defaults (visibility=15).
