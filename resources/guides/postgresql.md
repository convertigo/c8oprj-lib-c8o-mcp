# Convertigo Fast Path SQL PostgreSQL

Use the PostgreSQL JDBC URL, driver and dialect from the canonical connector example. Keep credentials in deployment symbols, use typed SQL variables, prove operations and project-save. Do not apply another database dialect blindly.
