# Convertigo Recipe Multipage App

Inventory the target project and standard marketplace libraries before building. Use _ui_ngx libraries for NGX. Delegate bounded constructor lots and verifier proofs where the harness supports them; read back reported QNames. Use generators for standard transactions, business sequences and pages. Keep a stable public contract, server-side session/role checks, and SQL persistence behind sequences. Pages call sequences with NGX events/actions; no direct scriptContent backend calls. Open the viewer early, prove backend and visible role flows, save through project-save and keep progress durable. Before deployment/export run mobile-builder-build; a green dev viewer alone is insufficient.
