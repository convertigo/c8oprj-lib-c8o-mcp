# Convertigo HTTP Business Sequence Recipe

Keep HTTP transport in HttpConnector and typed transactions, then call them from sequences with TransactionStep. For JSON use JsonHttpTransaction. Read back server/https/port/baseDir/subDir and RequestableHttpVariable.httpName. Use runtime Project.Connector.Transaction paths, never cn:/tr: QNames. Preserve the public variable name through RequestableVariable and StepVariable. Prove direct transaction then shaped business contract using only public inputs; HTTP status and metadata are insufficient. No hard-coded data or stub substitute after live failure. Fix the same rail from evidence, report missing proof, then project-save.
