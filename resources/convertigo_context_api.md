# Convertigo Context (minimal API)

The global `context` value exposed in Rhino is an instance of `com.twinsoft.convertigo.engine.Context` (see `convertigo-doc/reference-manual/convertigo-mbaas-server/javascript-objects-apis/index.md`). It is a Java object backed by the engine — **you must not attach custom fields such as `context.wordsData`** because Rhino forwards those assignments to the Java bean and they fail at runtime.

Use it only for the documented fields/methods summarized below. Everything else (temporary arrays, intermediate strings, etc.) should live in local JavaScript variables or in the dedicated storages (`project`, `server`, HTTP session, …).

## Frequently used fields (read/write when noted)

| Field | Type | Notes |
| --- | --- | --- |
| `context.contextID` | `String` | Identifier of the execution context. Useful for logging only. |
| `context.sequenceName` / `context.transactionName` | `String` | Names of the currently running requestable. |
| `context.project` | `Project` | Gives access to the current project object (use `project.get/set`). |
| `context.inputDocument` | `org.w3c.dom.Document` | Input XML generated by the requester. Read-only in most patterns. |
| `context.outputDocument` | `org.w3c.dom.Document` | Output XML being built; manipulate it through context helper methods. |
| `context.httpServletRequest` / `context.httpSession` | Servlet APIs | Use `getParameter`, `getHeader`, `getAttribute`, `setAttribute`, etc. |
| `context.isCacheEnabled` | `boolean` | Can be set to `false` inside a sequence to skip cache storage. |
| `context.lockPooledContext` | `boolean` | Ask Convertigo to keep a pooled context alive even if not in its stable screen class. |
| `context.requireEndOfContext` | `boolean` | Force destruction of the context after the current requestable. |

## Helper methods

Only call the documented helpers — they are guaranteed to exist across Studio/Server builds:

| Method | Purpose |
| --- | --- |
| `context.addTextNode(Node parent, String tag, String value)` | Insert an element with text under a specific node of `outputDocument`. |
| `context.addTextNodeUnderRoot(String tag, String value)` | Shorthand to append under the document root. |
| `context.addTextNodeUnderBlock(String tag, String value)` | Legacy helper for blocks in Transaction XML. |
| `context.abortRequestable()` | Ask Convertigo to stop the current sequence/transaction as soon as possible. |
| `context.encodeToHexString(String)` / `context.decodeFromHexString(String)` | Triple-DES helper matching the Studio “Ciphered” flag. |
| `context.getAuthenticatedUser()` / `context.setAuthenticatedUser(String)` / `context.removeAuthenticatedUser()` | Manipulate the authenticated user tied to the HTTP session. |

Refer to the official table “Context methods list” in the Convertigo Reference Manual for the exhaustive set.

## Sharing data safely

- **Inside the same sequence run:** declare normal JavaScript variables (`var wordsData = …;`). All Simple Steps and Json Steps share the same Rhino scope, so the iterator can reuse those locals without touching `context`.
- **Between sequences or requests:**
  - `project.set(key, value)` / `project.get(key)` for data shared across sessions of the same project.
  - `server.set(key, value)` / `server.get(key)` for engine-wide caches.
  - `context.httpSession.setAttribute(key, value)` / `.getAttribute(key)` to stick to the current user session.

## Forbidden / discouraged patterns

- `context.someCustomProperty = …` — fails because the Java bean exposes only whitelisted getters/setters.
- Assigning non-serializable objects to `context.outputDocument` or its nodes.
- Mixing context storage with JS locals (e.g. `context.wordsData` + `var wordsData`). Pick one of the safe storage mechanisms above.

When in doubt, consult the reference manual paragraph “Context object” (`reference-manual/convertigo-mbaas-server/javascript-objects-apis/index.md`).
